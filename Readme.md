## 📖 Overview

**LookSphere** is a modern, privacy-first social media platform built using the MERN stack (MongoDB, Express, React, Node.js). Originally starting as a pure React/JSON-server authentication practice app ("SecureAuth"), it has evolved into a robust, secure, and full-featured social networking platform.

It features a dark-theme-first aesthetic, stateless JWT authentication via Authorization headers, rich media sharing through Cloudinary, atomic post interactions (Sparks, Reshares, Archives), and a responsive, dynamic UI built with React 19 and Tailwind CSS.

---

## 🗺️ The Journey

LookSphere originally started as **SecureAuth**, a modern authentication app built with pure React.js and a JSON-server API deployed on Render. I built SecureAuth to practice when I first learned React. As I learned new technologies like Node.js, Express, MongoDB, Mongoose, and various other libraries, I wanted a real-world project to apply everything I was learning.

I decided to upgrade SecureAuth, converting it from a simple JSON-server API into a fully-fledged MERN stack web application. I was really enjoying the process, and I thought, "Why not build something we use every day?" So, I decided to build a social media platform. That led to the creation of LookSphere, and here it is today!

While it is continuously evolving as a hands-on project to practice high-performance full-stack engineering, this has been the incredible journey from SecureAuth to LookSphere.

## ✨ Key Features

- **Global Community & Discovery:** Explore global post feeds ([`/feed`](https://looksphere.vercel.app/feed)) with smooth autoplay videos, discover creators via debounced search ([`/creators`](https://looksphere.vercel.app/creators)), and browse posts in Explore ([`/explore`](https://looksphere.vercel.app/explore)).
- **Dynamic Post Interactions:** Real-time atomic **Sparks** (likes), **Reshares**, and private **Archives** with optimistic UI updates. Down-arrow count badges open an interactive modal ([`InteractionsListModal`](./frontend/src/modals/InteractionsListModal.jsx)) to inspect which users engaged.
- **Synchronized Profile Media Tabs:** Profile ([`/profile`](https://looksphere.vercel.app/profile)) showcases dynamic media tabs (Images, Videos, Reshares, Archived, Sparks) with automatic cross-tab interaction state synchronization without full-page reloads.
- **Account & Security Settings:** Dedicated Settings hub ([`/settings`](https://looksphere.vercel.app/settings)) with secure self-service **Change Email** ([`/settings/change-email`](https://looksphere.vercel.app/settings/change-email)) and **Change Password** ([`/settings/change-password`](https://looksphere.vercel.app/settings/change-password)) backed by Yup validation schemas.
- **Dedicated Post Page & Link Sharing:** Standalone post pages ([`/posts/:id`](https://looksphere.vercel.app/explore)), one-click link copying for profiles and posts, alt-text accessibility, and live impression telemetry.
- **Support & Inquiries Desk:** Comprehensive Contact Us portal ([`/contact-us`](https://looksphere.vercel.app/contact-us)) supporting multiple inquiry categories with image and video attachments. Users track admin responses under My Inquiries ([`/my-inquiries`](https://looksphere.vercel.app/my-inquiries)) and track administrative resolutions.
- **Offline Resilience & Error Boundaries:** Zero-delay fast-failing offline requests (`navigator.onLine`), real-time connectivity toasts, sanitized database driver error feedback, `localStorage` profile caching during network drops, and full-page/inline error boundaries with skeleton re-renders on retry.
- **High-Performance Architecture:** Zero Cumulative Layout Shift (CLS = 0) with locked 520px media containers, single-active coordinated video playback, GZIP/Brotli payload compression, and compound MongoDB covered indexes.
- **Robust Security & Data Integrity:** Passwords hashed via `bcrypt` (12 salt rounds), stateless JWT tokens via `Authorization: Bearer <token>` headers, strict CORS configuration, and dual-layer validation (`Yup` on frontend, `express-validator` on backend).

## 🛠️ Tech Stack

### **Frontend**
- **Core:** React, Vite, React Router
- **Styling & UI:** Tailwind CSS, Lucide React, React Spinners, React Toastify
- **Data & Forms:** Axios, React Hook Form, Yup
- **Tools & Config:** ESLint, Vercel deployment configuration
- **Algorithms & Performance:** Fisher-Yates (Knuth) Unbiased Shuffle ($O(N)$), Single-Active Viewport Decoupling, Invisible Sentinel IntersectionObserver ($O(M)$), Optimistic Referential Mutation ($<1\text{ms}$), Time-Decay Sliding Window Debounce (400ms)


### **Backend**
- **Core:** Node.js, Express.js
- **Database:** MongoDB & Mongoose (B-Tree compound covered indexes and cascading hooks)
- **Security & Auth:** JSON Web Tokens (JWT), bcrypt (12 rounds), CORS, Dotenv
- **Media & Storage:** Cloudinary (CDN image/video processing), Multer (multipart handling)
- **Utilities & Middleware:** Express Validator, Compression (GZIP/Brotli), Nodemon
- **Algorithms & Performance:** Dynamic Brotli (`br`) & DEFLATE Stream Compression, Vectorized Batch Index Scanning ($O(1)$ post enrichment), RAM Covered Index Scanning (`IXSCAN`), Micro-Batch Ingestion Pipeline (5–10 items)


### **Algorithms & Computational Architecture** ([Full Specification](./Algorithms.md))
- **Network & Compression:** Brotli (`br`) & DEFLATE (LZ77 + Huffman) payload compression (70–85% bandwidth reduction fitting inside initial TCP `initcwnd` ~14.6KB), Micro-Batch Ingestion Pipeline (5–10 items for sub-100ms FCP and $<15\text{MB}$ memory footprint)
- **Viewport & Feed Permutation:** Single-Active Viewport Decoupling (mutual-exclusion playback coordinator restricting active hardware decoders to exactly 1), Fisher-Yates (Knuth) Unbiased Shuffle ($O(N)$ with `sessionStorage` disjoint seen-post partitioning), Invisible Sentinel IntersectionObserver ($O(M)$ hash set deduplication)
- **State & Concurrency:** Optimistic State Mutation ($<1\text{ms}$ with referential integrity preservation for `React.memo`), Multi-Setter Fan-Out Synchronizer, Time-Decay Sliding Window Debounce (400ms) with dynamic cache-bypass
- **Database & Query Optimization:** Vectorized Batch Index Scanning ($O(1)$ single-trip DB enrichment with in-memory hash mapping eliminating $N+1$ queries), B-Tree Compound Covered Indexes (`IXSCAN` in RAM eliminating document collection fetches)
